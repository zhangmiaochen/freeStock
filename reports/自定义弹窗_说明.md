# 自定义确认/输入弹窗（替代系统弹窗）

日期：2026-11-09

## 背景

项目里原来用 `window.confirm` / `window.prompt`，样式由操作系统决定，
和深色主题完全不一致，按钮文案也不能改。现在统一换成自定义组件。

## 结构

| 文件 | 作用 |
|---|---|
| `frontend/src/lib/dialog.ts` | 全局单例 + `confirmDialog()` / `promptDialog()`，返回 Promise |
| `frontend/src/components/ui/dialog/DialogHost.vue` | 用 reka-ui Dialog 原语渲染；挂在 `App.vue` 根部 |
| `frontend/src/App.vue` | 挂载 `<DialogHost />` |

## 用法

```ts
import { confirmDialog, promptDialog } from "@/lib/dialog";

// 确认
if (!(await confirmDialog({
  title: "删除组合",
  message: "持仓与流水会一起删除，且不可恢复。",
  confirmText: "删除",
  danger: true,
}))) return;

// 输入
const input = await promptDialog({
  title: "设置本金",
  message: "本金用于把推荐权重换算成股数。",
  defaultValue: "100000",
  inputSuffix: "元",
});
if (input === null) return; // 取消
```

## 交互与样式

- 深色主题卡片、圆角、阴影、遮罩模糊；
- `danger: true` 时确认按钮为红色（destructive）；
- Esc / 点遮罩 = 取消；输入框回车 = 确认；
- 打开时输入框自动聚焦并全选；
- 已有弹窗未关闭时再次调用，会先把上一个按"取消"结算，Promise 不会悬挂。

## 已替换的位置

| 位置 | 原实现 | 现实现 |
|---|---|---|
| 应用调仓建议 | `window.confirm` | `confirmDialog` |
| 删除组合 | `window.confirm` | `confirmDialog`（危险） |
| 删除持仓 | `window.confirm` | `confirmDialog`（危险） |
| 设置本金 | `window.prompt` | `promptDialog` |

全项目已无 `window.confirm / alert / prompt`（`grep` 只剩注释）。

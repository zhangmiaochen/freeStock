## 一、策略目的：它想赚什么钱

### 1.1 一句话

> **在长期趋势向上的好公司里，等它短期回调时买入，涨回正常位置就卖出。**

### 1.2 三个赚钱来源

| 来源 | 说明 |
|---|---|
| **质量溢价** | 长期赚钱（ROE 高）、毛利高、现金流好、负债低的公司，估值中枢会慢慢上移 |
| **成长溢价** | 营收和利润还在增长的公司，业绩会推着股价走 |
| **波段收益** | 好公司也会短期跌 10%~20%，在回调时买、涨回去卖，赚这部分波动 |

### 1.3 它不赚什么钱

- 不赌重组、不炒题材、不看消息；
- 不做短线打板，也不做长期死拿；
- 不预测大盘点位，只用均线决定"要不要减半仓"。

## 二、策略逻辑：为什么是这几个条件

| 条件 | 解决什么问题 | 不这么做会怎样 |
|---|---|---|
| **ROE ≥ 8%** | 公司得真赚钱 | 买到"讲故事但不赚钱"的公司 |
| **营收/净利同比 ≥ 0** | 业绩不能下滑 | 买到业绩变脸的下跌趋势股 |
| **毛利率 ≥ 15%** | 产品有定价权 | 买到靠低价走量、一降价就亏的公司 |
| **资产负债率 ≤ 70%** | 熊市里活得下来 | 高杠杆公司在收紧时先崩 |
| **经营现金流/净利 ≥ 0.3** | 利润是真钱不是应收账款 | 赚的是纸面利润，暴雷风险高 |
| **收盘 > MA200** | 只做长期向上的 | 抄底下跌趋势，越抄越跌 |
| **20 日回撤 −2% ~ −20%** | 买在回调，不追高也不接刀 | 追高买在顶，或抄底买在半山腰 |
| **每月调仓、涨出回调带就卖** | 把波段利润落袋 | 坐过山车，涨回去又跌回来 |
| **8 只、单票 ≤ 15%** | 分散但不平庸 | 单票重仓，一次暴雷伤筋动骨 |
| **沪深300 < MA200 时半仓** | 系统性下跌时少亏 | 满仓扛熊市，回撤失控 |

### 2.1 为什么"回调"要用 20 日回撤，而不是跌到均线

- 20 日回撤衡量的是"离最近高点跌了多少"，比均线更贴近"短期情绪"；
- 上限 −2%：太接近高点说明没回调，不买；
- 下限 −20%：跌太深说明可能出问题，不接飞刀。

### 2.2 为什么是"月度波段"而不是长期持有

策略赚的是"回调→反弹"这一段。历史上：
- 平均持有 **1.67 个月**；
- 强制拿更久（最短持有 2/3/4 个月）收益分别掉到 441%/302%/321%（基准 521%）；
- 说明**涨出回调带就卖**是收益的一部分，不是缺点。

## 三、股票池与数据口径

### 3.1 股票池

- 沪深 A 股：主板 + 创业板 + 科创板；
- **不含北交所**；
- 上市满 **250 个交易日**；
- 20 日平均成交额 ≥ **3000 万元**（剔除流动性太差的）。

> 板块测试结论：全 A 股最好（年化 16.4%），只做主板+创业板 14.4%，
> 单做主板只有 7.8%、单做创业板 10.6%、单做科创板 7.4%。

### 3.2 财务数据必须"当时可见"（PIT）

- 只用 **公告日 ≤ 调仓日** 的财报；
- 取**最新报告期**（不是最新公告日）——防止一条 2024 年发布的 2010 年报更正
  把 2023 年报盖掉；
- 同一报告期有多次公告（更正），取公告日最新的那条。

## 四、选股条件（必须全部满足）

### 4.1 硬性过滤（6 条财务 + 2 条行情）

| # | 条件 | 阈值 | 说明 |
|---|---|---|---|
| 1 | ROE（年化） | ≥ 8% | Q1×4、Q2×2、Q3×4/3、Q4×1 |
| 2 | 营收同比 | ≥ 0% | 体量还在长 |
| 3 | 净利同比 | ≥ 0% | 利润还在长 |
| 4 | 毛利率 | ≥ 15% | 有定价权 |
| 5 | 资产负债率 | ≤ 70% | 杠杆可控 |
| 6 | 经营现金流 / 净利 | ≥ 0.3 | 利润含金量 |
| 7 | 收盘价 | > MA200 | 长期趋势向上 |
| 8 | 20 日回撤 | −20% ~ −2% | 回调到位 |

**任何一条不满足，直接不进候选池。**

### 4.2 综合打分（通过过滤的股票一起排名）

```
质量 = 0.6 × 排名(ROE) + 0.4 × 排名(毛利率)
成长 = 0.5 × 排名(营收同比) + 0.5 × 排名(净利同比)
安全 = 0.5 × 排名(−资产负债率) + 0.5 × 排名(现金流/净利)
总分 = 0.4 × 质量 + 0.4 × 成长 + 0.2 × 安全
```

- 排名是**截面百分位**：池子里最好的 = 1，最差的 = 1/N；
- 并列值取**平均名次**（避免同一档公司分数随机）；
- 取总分**前 8 名**。

## 五、买入条件

### 5.1 什么时候买

- **每个月最后一个交易日收盘后**计算；
- 次日（下月第一个交易日）**开盘价**买入。

### 5.2 买什么、买多少

| 名次 | 权重（满仓时） |
|---|---:|
| 第 1 名 | 15% |
| 第 2 名 | 15% |
| 第 3 名 | 15% |
| 第 4 名 | 15% |
| 第 5 名 | 15% |
| 第 6 名 | 约 13% |
| 第 7 名 | 约 8% |
| 第 8 名 | 约 4% |

- 基础权重按 `0.05 + 名次²` 分配（第 1 名最重、第 8 名最轻）；
- **单票硬上限 15%**，超过的部分按比例分给其余票；
- 所以前 5 名通常都顶到 15%，差异体现在后 3 名。

### 5.3 熊市怎么办

- 沪深300 收盘价 < 它的 MA200 → **总仓位 × 0.5**；
- 每只票权重减半（约 2%~7.5%），**照常选股、照常买入**，不是空仓。

### 5.4 不买的情况

- 开盘涨停 / 停牌 → 跳过，不追；
- 现金不够 → 按名次顺序买，买满为止；
- 候选不足 8 只 → 有几只买几只，剩余现金留着，不降级补位。

## 六、卖出条件

### 6.1 什么时候卖

**每个月最后一个交易日**检查一次，以下任一情况 → 次日开盘卖出：

| 情况 | 动作 |
|---|---|
| 不在新一期前 8 名名单里 | **全部卖出** |
| 在名单里，但目标权重比当前低 | 减仓到目标权重 |
| 在名单里，权重差 < 1% 总资产 | **不动**（免打扰带） |
| 持有期间涨出回调带（> −2%） | 下个月自然掉出名单 → 卖出 |
| 跌破 MA200 / 基本面变差 | 下个月自然掉出名单 → 卖出 |

### 6.2 没有的东西

- **没有个股止损**：实测 25% 止损 13.7 年只触发 28 次、收益影响是噪声级；
- **没有止盈**：涨出回调带就是止盈；
- **没有补仓/摊平**：亏了也不加。

### 6.3 为什么亏着也卖

因为掉出名单通常意味着：跌破 MA200、基本面变差、或涨出回调带。
历史上"等回本再卖"的测试结果是：
- 等回本（不限时）：+209%（基准 638%）；
- 等回本（最多 6 个月）：+371%；
- 回到 −10% 再卖：+611%（略低于基准，回撤小一点）。

**结论：掉出名单就卖，是数据支持的最优做法。**

## 七、交易执行细节

| 项目 | 规则 |
|---|---|
| 调仓频率 | **每月一次**（最后一个交易日收盘后算） |
| 成交时间 | **次日开盘**（T+1 开盘价） |
| 买入成本 | 佣金 0.03% + 滑点 0.1% |
| 卖出成本 | 佣金 0.03% + 印花税 0.1% + 滑点 0.1% |
| 免打扰带 | 权重偏离 < 总资产 1% 不下单 |
| 仓位单位 | 100 层，1 层 = 1% 总资产（所以 15% = 15 层） |

## 八、完整流程（伪代码）

```
每月最后一个交易日 15:30 后：

1. 取财报：announce_date ≤ 今天，按报告期取最新一期
2. 过滤股票池：
     上市 ≥ 250 交易日
     20 日均额 ≥ 3000 万
     ROE(年化) ≥ 8% 且 营收同比 ≥ 0 且 净利同比 ≥ 0
     毛利率 ≥ 15% 且 负债率 ≤ 70% 且 现金流/净利 ≥ 0.3
     收盘 > MA200
     −20% ≤ 20日回撤 ≤ −2%
3. 打分：质量 0.4 + 成长 0.4 + 安全 0.2（截面百分位）
4. 取前 8 名
5. 算权重：0.05 + 名次² → 归一化 → 单票 cap 15%
6. 熊市系数：沪深300 < MA200 → 权重 × 0.5
7. 生成订单：
     不在名单的持仓 → 全部卖出
     名单内偏离 ≥ 1% → 买入/卖出到目标
8. 次日开盘执行；涨停/停牌跳过
```

## 十一、策略特性（必须知道的）

1. **回撤大**：−46%，2015、2018、2021 三次；这不是稳健型策略。
2. **2021-2023 连续三年小亏**（−12.8% / −12.0% / −6.2%）：成长股杀估值阶段它一定难受。
3. **牛年很猛**：2015 +82%、2020 +48%、2024 +45%、2025 +61%。
4. **换手高**：平均持有 1.67 个月，每月约 5 买 5 卖，必须程序化执行。
5. **熊市半仓**：不是空仓，会参与反弹，也会受伤。
6. **不会长期持有**：涨出回调带就卖，别指望它拿住十倍股。

### 它适合谁

- 能接受 −45% 级别回撤、追求长期年化 15% 左右的人；
- 有程序化执行能力（每月自动下单）的人；
- 不适合：不能承受深回撤、想长期持有、想每年都赚钱的人。

## 十二、已测试但**不要**加的东西（避免重复踩坑）

| 想法 | 测试结果 |
|---|---|
| 提高熊市仓位（0.7/0.8/1.0） | 收益升、回撤同步升，慢熊里更差（卡玛不变） |
| 熊市空仓 | +376%（基准 638%），大幅跑输 |
| ROE 趋势 / 增速加速度 | 全部更差（收益降 15%~50%） |
| 25% 个股止损 | 噪声级，只在 2018 年生效 |
| 多策略组合（+趋势低吸） | 被 2026 单年误导，剔除后更差 |
| 行业动量 / 行业上限（2020+） | 全部大幅跑输 |
| PE 分位过滤（2016+） | 阈值 50%~90% 结果乱跳，过拟合 |
| 最短持有 2/3/4 个月 | 全部更差（441%/302%/321%） |
| 最长持有 2/3/6/12 个月 | 2→3 月跳 250pp，3→6 月又掉回，噪声 |

**结论：v3 在当前数据与框架下是局部最优。**

## 十三、一句话总结

**质量成长 · 趋势回调 V3 = 8 只、每月调仓的"好公司回调买入"波段策略：
用 ROE/成长/现金流筛掉烂公司，用 MA200 只做上升趋势，用 20 日回撤买回调，
涨出回调带就卖，熊市半仓，单票封顶 15%。
13.7 年 +654%、年化 16.5%、最大回撤 −46%，代价是 2021-2023 这类年份会连续小亏。**

## 0. 策略一句话

> 在 **MA200 上方**的 A 股里，选出**盈利质量好、成长为正、财务安全**的公司；
> 等它**回调 2%~20%** 时买入；持仓 **8 只**，按综合得分平方分配权重、**单票硬上限 15%**；
> 每月最后一个交易日收盘出信号、**次日开盘**成交；
> 沪深 300 在 MA200 下方时**总仓位减半**；权重偏离不到总资产 1% 就不交易。

目标：长期年化 15% 左右、最大回撤约 −47%、每年亏损不超过 17%。

## 1. 数据需求

| 数据 | 来源（现有） | 用途 | 关键字段 |
|---|---|---|---|
| 日线 | `daily_bars` | 收盘价、开盘价、成交额、均线、回撤 | symbol, trade_date, open, close, amount |
| 财报 | `financial_statement_items` | 基本面过滤与打分 | symbol, report_period, item_code, item_value, **announce_date** |
| 指数 | `index_bars` | 熊市判断 | 000300.SH 的 close |
| 股票列表 | `instruments` | 上市日期、排除退市 | symbol, list_date, delist_date |

### 1.1 财报字段映射（`item_code`）

| 用途 | item_code |
|---|---|
| ROE | `roe` |
| 营收同比 | `revenue_yoy` |
| 净利同比 | `net_profit_yoy` |
| 毛利率 | `gross_margin` |
| 总资产 / 总负债 | `total_assets` / `total_liabilities` |
| 经营现金流 / 净利 | `net_cash_operate` / `net_profit` |

### 1.2 时点（PIT）规则（最重要）

```
对每个 (symbol, 调仓日 T)：
  候选 = 所有 announce_date <= T 的财报记录
  按 report_period 取**最新一期**（2024Q3 > 2024Q2 > ...）
  同一期内如有多次公告（更正），取 announce_date 最大的一条
```

> ⚠ 不要用“最新公告”来选：一条 2024 年发布的 2010 年报更正会把 2023 年报盖掉。
> 必须“先按报告期取最新，再按公告日取最新”。

**绝对禁止**：使用 `announce_date > T` 的任何财务数据；使用 `report_period` 晚于 T 的数据。

## 3. 股票池与过滤（按顺序）

```
1) 沪深 A 股（600/601/603/605/000/001/002/003/300/301/302/688/689），排除北交所
2) 上市满 250 个交易日（用该股第一根有效日线算）
3) 当日收盘价 > 0（停牌不买）
4) 20 日平均成交额 >= 3000 万元
5) 最新一期财报满足：
     ROE_annualized >= 8%
     营收同比 >= 0
     净利同比 >= 0
     毛利率 >= 15%
     资产负债率 <= 70%
     经营现金流 / 净利 >= 0.3（净利 <= 0 直接淘汰）
6) 收盘价 > MA200（200 日简单均线，至少 160 个有效值）
```

**ROE 年化**：`roe_annual = roe × 4 / 季度数`
（Q1×4、Q2×2、Q3×4/3、Q4×1；季度数取自 `report_period` 的 Q 后缀）

> **板块范围说明（实测，见 `板块组合_对比.md`）**：
> 用"全部 A 股"（主板+创业板+科创板）最好：2013-2026 年化 15.67%、回撤 47.4%；
> 只做"主板+创业板"是 14.35%、回撤 47.4%（少 1.3pp/年）；
> 单板块明显更差（主板 7.8%、创业板 10.6%、科创板 7.4%）；
> "主板+科创板"是最差组合（2020-2026 仅 3.7%/年）。
> **默认按全部 A 股实现**；如果组合被限定为"主板+创业板"，逻辑不变、收益略降。

**资产负债率** = `total_liabilities / total_assets × 100`；分母为 0 或负 → 淘汰。

## 4. 打分（截面百分位）

在**通过第 3 节全部过滤**的股票池内计算（注意：此时**不含**回调条件）：

```
质量 = 0.6 × rank_pct(ROE_annual) + 0.4 × rank_pct(毛利率)
成长 = 0.5 × rank_pct(营收同比)   + 0.5 × rank_pct(净利同比)
安全 = 0.5 × rank_pct(−资产负债率) + 0.5 × rank_pct(经营现金流/净利)
总分 = 0.4 × 质量 + 0.4 × 成长 + 0.2 × 安全
```

`rank_pct` = 从小到大排名 / 样本数（最大 = 1.0，最小 = 1/N）。
缺失值直接淘汰，不参与排名。

## 5. 每月调仓流程（最后一个交易日收盘后）

### 5.1 候选池

在通过第 3 节的池子里，再要求**回调条件**：

```
dd20 = close / max(close, 过去20个交易日) − 1
−20% <= dd20 <= −2%
```

（`max` 含当日；至少 15 个有效值）

### 5.2 目标名单

按总分降序取前 **8** 只。
**已持有的股票不享受豁免**——如果它涨出回调带（dd20 > −2%），下个月就会被卖掉。
这是策略的“波段”属性，不要“优化”成长期持有（实测会少赚 28%）。

### 5.3 权重（score² + 15% 上限）

对名单内 8 只，按分数降序排名 `r = 1.0, 0.875, 0.75, ..., 0.125`：

```
raw_i = 0.05 + r_i²
w_i   = raw_i / Σ raw
```

然后做**单票上限 15% 的迭代配平**：

```
repeat up to 20 times:
    over = { i : w_i > 0.15 }
    if over is empty: break
    excess = Σ_{i∈over} (w_i − 0.15)
    w_i = 0.15 for i ∈ over
    rest = 未超限的
    w_j += excess × w_j / Σ_{rest} w_j   for j ∈ rest
```

> 参考分布（2025-06-30 实测）：`15% ×5 + 12.9% + 7.6% + 4.4%`。
> 由于平方权重很陡，上限会把前 5 名都压到 15%，差异主要体现在后 3 名。
> **这是预期行为**，不要改成“只压第一名”。

### 5.4 总仓位（熊市减半）

```
bench = 沪深300 收盘；bench_ma = 沪深300 的 MA200
exposure = 0.5 if bench < bench_ma else 1.0
最终个股权重 = w_i × exposure
```

熊市里**照常选股、照常开仓**，只是每只票的仓位减半（约 4%~7.5%）。

### 5.5 下单（1% 免打扰带）

```
对每只目标股：
    target_value = 组合总资产 × w_i × exposure
    current_value = 持仓股数 × 最新价
    delta = target_value − current_value
    if |delta| < 组合总资产 × 1%: 跳过（不动）
    否则按 delta 买入/卖出
对不在名单里的持仓：全部卖出（不受 1% 带限制）
```

**卖出先于买入**；先卖出的现金用于买入。

### 5.6 执行

- 信号日：每月最后一个交易日的**收盘后**；
- 成交日：**下一个交易日开盘价**（集合竞价/开盘价成交）；
- 开盘价无法成交（涨停/停牌）时：**跳过该笔，不追**，等下次调仓再说。

### 5.7 成本

- 买入：`金额 × (1 + 0.13%)`
- 卖出：`金额 × (1 − 0.23%)`
- 回测已按此扣除；实盘佣金若不同，替换对应系数即可。

## 6. 边界情况（必须处理）

| 情况 | 处理 |
|---|---|
| 候选不足 8 只 | 有几只买几只，剩余现金留存；不降级补位 |
| 持仓股停牌（当日无价） | 用最近一个有效收盘价估值；调仓日无法卖出则保留到下个月 |
| 持仓股退市 | 以最后有效价卖出，计入亏损 |
| 新股无 250 日 | 不买 |
| 财报缺失 | 该股不进池 |
| 财报为负净利 | 现金流比无法计算 → 淘汰 |
| 目标股开盘涨停 | 跳过买入（不追高） |
| 目标股开盘跌停 | 跳过买入（不接刀） |
| 组合现金不足 | 按权重顺序（分数降序）依次买，买满为止 |
| 单票上限 15% 但只选出 3 只 | 最多 45% 仓位，其余现金；不加杠杆 |

## 8. 验证结论（为什么可以信）

1. **无未来函数**：财报 `announce_date <= T`；T 日收盘出信号、T+1 开盘成交；
   财报再滞后 30 天结果几乎不变（638→621）。
2. **不过拟合**：8 组邻域参数全部为正（最差 +392%、年化 12.3%）；
   逐年 walk-forward（过去 3 年选参）2017-2026 累计 **+334%**，跑赢固定 v3 的 +277.5%。
3. **执行敏感**：信号推迟一天（T+2 成交）收益降到 392%——实盘必须严格次日开盘执行。

## 11. 参考实现（Python 伪代码）

```python
# 每月最后一个交易日 T 收盘后
def rebalance(T, holdings, cash):
    # 1) 财报 PIT
    fin = latest_report_asof(T)          # 先按 report_period，再按 announce_date
    # 2) 过滤
    pool = a_shares(alive=True)
    pool = pool[listed_days(pool) >= 250]
    pool = pool[amount20(pool) >= 3e7]
    pool = pool[roe_annual(fin) >= 8]
    pool = pool[rev_yoy(fin) >= 0]
    pool = pool[np_yoy(fin) >= 0]
    pool = pool[gross_margin(fin) >= 15]
    pool = pool[debt_ratio(fin) <= 70]
    pool = pool[ocf_ratio(fin) >= 0.3]
    pool = pool[close(T) > ma200(T)]
    # 3) 回调
    dd = close(T) / rolling_max(close, 20, T) - 1
    entry = pool[(dd <= -0.02) & (dd >= -0.20)]
    # 4) 打分
    score = 0.4 * quality(entry) + 0.4 * growth(entry) + 0.2 * safety(entry)
    target = score.nlargest(8)
    # 5) 权重
    r = np.linspace(1.0, 1/8, 8)
    w = (0.05 + r**2); w /= w.sum()
    w = cap_weights(w, 0.15)             # 迭代配平
    expo = 0.5 if csi300(T) < csi300_ma200(T) else 1.0
    w *= expo
    # 6) 下单
    orders = []
    for sym, pos in holdings.items():
        if sym not in target:
            orders.append(("SELL_ALL", sym))
    equity = cash + sum(holdings.values() * price(T))
    for sym, wi in w.items():
        delta = equity * wi - holdings.get(sym, 0) * price(T)
        if abs(delta) >= equity * 0.01:
            orders.append(("BUY" if delta > 0 else "SELL", sym, abs(delta)))
    # 7) T+1 开盘执行，涨停/停牌跳过
    return orders
```

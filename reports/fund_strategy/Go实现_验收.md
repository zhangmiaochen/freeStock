## 2. 实现口径（与 `开发说明_v3.md` 一致）

- **股票池**：沪深 A 股（600/601/603/605/000/001/002/003/300/301/302/688/689），不含北交所；
- **PIT 财报**：`announce_date <= 调仓日`，先取最新 `report_period`，同周期取最新公告；
- **过滤**：上市≥250 日（用 `list_date` + 365 自然日近似）、20 日均额≥3000 万、ROE(年化)≥8、营收/净利同比≥0、毛利≥15%、负债≤70%、现金流/净利≥0.3、收盘>MA200、20 日回撤 ∈ [−20%, −2%]；
- **打分**：质量 0.6/0.4、成长 0.5/0.5、安全 0.5/0.5，总分 0.4/0.4/0.2，截面百分位；
- **权重**：`raw = 0.05 + r²` 归一化，单票上限 15%，迭代配平（超限部分永久封顶，剩余按比例分给未封顶的）；
- **仓位**：沪深300 < MA200 时权重 ×0.5；
- **调仓**：每月最后一个交易日出信号，引擎按次日开盘撮合；
- **免打扰带**：权重换算成 100 层（1 层 = 1% 总资产），层数变化为 0 就不下单——等价于 1% 带；
- **成本**：佣金 0.03%（最低 5 元）+ 印花税 0.1%（卖）+ 滑点 0.1%。

## 3. 与 Python 参考实现的对照（同一份数据湖）

### 2020-01-01 ~ 2025-12-31（6 年，含 2021-2023 熊市）

| 指标 | Go 实现 | Python 参考 | 差异 |
|---|---:|---:|---:|
| 总收益 | **+119.80%** | +120.88% | **−1.08pp** |
| 年化 | **14.61%** | 14.35% | +0.26pp |
| 最大回撤 | **−45.75%** | −44.72% | −1.03pp |
| 夏普 | 0.46 | 0.60 | −0.14 |
| 订单数 | 378 | 806 | 统计口径不同 |

### 2024-01-01 ~ 2025-12-31（2 年，单边上涨）

| 指标 | Go 实现 | Python 参考 | 差异 |
|---|---:|---:|---:|
| 总收益 | **+125.91%** | +121.57% | **+4.34pp** |
| 年化 | **52.72%** | 51.55% | +1.17pp |
| 最大回撤 | **−20.94%** | −20.64% | −0.30pp |
| 夏普 | 1.87 | 1.60 | +0.27 |
| 订单数 | 112 | 257 | 统计口径不同 |

> 已做确定性校验：同一区间连跑两次结果一致（2020-2025 两次均为 +119.80%；2024-2025 两次均为 +125.91%）。

**结论**：6 年窗口总收益差 1.1pp、年化差 0.26pp、回撤差 1pp——实现口径一致，剩余差异可解释：

1. **复权口径**：Go 用数据源（`DailyHistory`）的复权价，Python 用原始价 + 自建拆股调整，长期收益会有小幅漂移；
2. **层数取整**：Go 把权重四舍五入成 1% 的整数层（也顺带实现了 1% 免打扰带），Python 用连续权重；
3. **成本细节**：Go 有 5 元最低佣金，Python 没有；
4. **订单计数**：Python 统计"每笔委托"（含微调），Go 引擎按自身成交事件计数，所以 378 vs 806；
5. **夏普**：两者对无风险利率/波动率年化的处理不同。

### 3.2 回测与建议"同源"（不是两套逻辑）

回测和最新交易日建议共用两个函数：

| 函数 | 作用 |
|---|---|
| `qGrowthTargets(rows, cfg, expo)` | rows → 目标层数（score² 权重、15% 上限、熊市 ×0.5、1 层=1%） |
| `qGrowthPlanRows(held, rows, target)` | 目标层数 vs 当前持仓 → 加/减/清仓计划行（层数不变不出行 = 1% 带） |

- 回测：`qGrowthPlanBuilder` 每天先算 `qGrowthTargets`，再调 `qGrowthPlanRows`；
- 建议：`buildQualityGrowthPlanAt` 同样先算 `qGrowthTargets`，再调 `qGrowthPlanRows`。

**一致性测试**（`TestQualityGrowthPlanReal` 内置）：
取同一交易日，分别用回测侧的计划构建器和实盘建议生成计划，逐票比较目标层数——
实测 8 只全部一致：

```
一致性检查通过：回测与建议的目标层数完全一致（8 只）
```

这保证"回测里怎么调仓"和"页面上给的建议"是同一套规则，不会出现"回测赚钱、建议另一套"的情况。

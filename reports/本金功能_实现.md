# 本金功能 · 后端实现进度

日期：2026-11-09

## 已完成（后端）

### 1. 资金账户表（自动建，老库无需迁移）

`internal/portfolio/money.go`：

```sql
portfolio_money(portfolio_id, initial_capital, cash, updated_at)
position_shares(portfolio_id, ts_code, shares)
```

单独建表而不是给 `portfolio` / `portfolio_position` 加列 —— 那两张表的 SQL 全是显式列名，
加列要改所有读写路径，风险高；资金是新增能力，独立存更安全。

### 2. Store API

- `GetMoney` / `SetMoney`：读/写本金与现金（默认 10 万）
- `SetInitialCapital`：改本金，并按"本金 − 持仓成本"重置现金
- `SharesMap` / `SetShares`：读/写每只持仓股数

### 3. Service API（给界面用）

- `GetPortfolioMoney(portfolioID)` → 初始本金、现金、持仓市值、**当前权益**、收益率
- `SetPortfolioCapital(portfolioID, capital)` → 改本金并重新同步
- `SyncPortfolioMoney(portfolioID)` → 按层数把权益换算成整手股数、重算现金

口径：

```
当前权益 = 现金 + Σ 股数 × 原始收盘价
目标股数 = floor(层数/总层数 × 权益 / 价格 / 100) × 100
现金     = 权益 − Σ 目标股数 × 价格
```

### 4. 计划带资金列

`score.RotationRow` 新增 `targetShares` / `targetAmount` / `affordable`；
`PlanResult` 新增 `moneyEquity` / `moneyCash`。

质量成长计划构建时自动填充（其它策略为 0，不影响）。

### 5. 实盘也启用可负担过滤

`buildQualityGrowthPlanAt` 用**当前权益**作为本金，按"一手买不买得起"筛候选 ——
与回测 `Affordable` 同一套规则。回测实测：10 万本金年化 6.81% → **11.30%**。

### 6. 应用/增删持仓后自动同步

`applyRotationWithPlan` 成功后调用 `syncMoneyFor`（仅质量成长），
股数和现金随最新权益更新，本金随盈亏变化。

### 7. 回测

引擎新增 `LotSize`（质量成长传 100，其它策略默认 1）；
`BacktestRequest.Affordable` 打开可负担过滤。

## 全部策略通用（本次扩展）

资金不再只对质量成长生效：

| 能力 | 覆盖范围 |
|---|---|
| 资金账户（本金/现金/股数） | 所有策略 |
| 计划行目标股数/金额/买不起标记 | 所有策略（`BuildPlan` 统一调用 `ApplyMoneyToPlan`） |
| 调仓后同步股数与现金 | 所有策略（`syncMoneyFor` 去掉策略判断） |
| 增删持仓后同步 | 所有策略（`AddPosition` / `DeletePosition` 后调用） |
| 回测按 100 股整手 | 所有策略（通用回测配置也加了 `LotSize: 100`） |

层数体系不同但口径一致：目标金额 = 权益 × 目标层数 / 总层数，再按 100 股整手向下取整；
一手金额超过目标金额时标记为「买不起」（质量成长会用它跳过候选，10 层制策略只标记、不跳过）。

`TestApplyMoneyToPlanLowBuy` 验证：10 万本金、10 层制、目标 3 层 → 600 股；
目标 2 层、股价 1000 元（一手 10 万 > 2 万预算）→ 0 股、标记买不起。

# 资金约束下的质量成长：优化探索（第一轮，未改代码）

日期：2026-11-09
范围：质量成长 + 趋势回调（主板+创业板）
区间：2020-01-01 ~ 2026-10-28（除注明外）；A 股 100 股整手、佣金 0.03%（最低 5 元）、印花税 0.1%、滑点 0.1%

## 一、现状：钱少不是"少赚一点"，是"一半收益"

| 本金 | 年化 | 说明 |
|---:|---:|---|
| 5 万 | 2.74% | 大量买不进，长期半仓现金 |
| **10 万** | **6.81%**（可负担过滤后 **11.30%**） | 当前配置 |
| 20 万 | 10.34% | |
| 30 万 | 12.73% | 接近满仓效果 |
| 1000 万 | 14.36% | ≈无约束 |

**损失来源**（10 万、8 只、单票上限 15%）：

- 单仓预算 = 本金 × 权重，前 2 名 15% → 1.5 万、后几名 6% → 0.6 万；
- 一手成本 = 股价 × 100：股价 >150 元的票，15% 仓位都买不起；股价 >60 元的票，6% 仓位买不起；
- 买不起 → 引擎买 0 股 → 现金闲置 → 收益被摊薄；
- 熊市再 ×0.5 时预算更小，**能买的票更少**。

## 二、本轮测过的杠杆（Python 研究引擎，无资金约束，2020-2026）

| 配置 | 年化 | 回撤 | 夏普 | 结论 |
|---|---:|---:|---:|---|
| n=5、score² | 2.32% | −58.8% | 0.16 | 5 只 + 15% 上限 → 权重和不足 1，现金太多，差 |
| n=6 | 10.95% | −47.0% | 0.45 | 略好于 8 只 |
| **n=8（基准）** | **10.37%** | −45.3% | 0.44 | |
| n=10 | 8.69% | −45.9% | 0.38 | 更差 |
| n=12 | 7.41% | −46.0% | 0.34 | 更差 |
| n=8 等权（12.5%） | **12.00%** | −44.8% | 0.50 | 短期窗口最好 |
| n=8 等权，2013-2026 | 14.26% | −48.4% | 0.58 | 长窗口与 score²(14.21%) 几乎一样 |
| n=8 等权，双月调仓 | 0.71% | −51.9% | 0.09 | 双月调仓是灾难，必须月频 |
| n=8 等权，熊市不减半 | 12.77% | −55.5% | 0.49 | 收益 +0.8pp，回撤 +10pp |

**结论：**

1. **持仓数不能少**（n=5 灾难，n=6 略好但集中度风险大）也不能多（n≥10 稀释）；
2. **等权在短窗口明显更好**（12.0% vs 10.4%），长窗口两者持平——等权最大的价值是**每个仓位预算一致 = 12.5%**，对小资金更友好（不会出现"后几名 6% 买不起"）；
3. **双月调仓是灾难**，月频不能动；
4. **熊市减半在资金约束下可能是负贡献**（预算本就小，再减半更买不进），但回撤会变大，需要带资金约束实测。

## 三、下一步要测的（需要少量代码改动，按优先级）

1. **可负担判断改用"实际权重"而不是"单票上限 15%"**
   现在过滤用 15% 预算判断，但实际后几名只有 6%，导致"过滤放行、下单买不起"。
   改成按实际权重的预算判断，能减少"空买"和现金闲置。

2. **等权（12.5%）作为可选权重模式**
   短窗口 +1.6pp，且每个仓位预算一致，对小资金更友好。需要带资金约束在 Go 里验证。

3. **现金再利用**
   调仓时如果还有现金（买不起的票留下的），按排名加给已持有的、未到 15% 上限的票；
   相当于"用不满 8 只时集中一点"，可能把闲置现金的拖累降下来。

4. **熊市系数在资金约束下重测 0.5 / 0.75 / 1.0**
   Python（无资金约束）显示 1.0 收益更高但回撤大 10pp；带资金约束可能更有利（预算不被腰斩）。

5. **最低本金建议**
   数据已经很清楚：**10 万 ≈ 11.3%、30 万 ≈ 12.7%、100 万 ≈ 13.2%**。
   如果目标是"接近策略本身 14%+ 的水平"，本金应 ≥ 30 万；10 万只能拿到 11% 左右。

## 四、我的建议

先做 **1 + 2 + 3** 三项（都要改 Go 计划构建器，属于策略参数/执行细节，不是重写）：

- 1 是修正"过滤口径"（纯 bug 级改进，几乎不增加风险）；
- 2 是加一个 `weight_mode=equal` 开关，回测/实盘同一套；
- 3 是现金再利用，能直接对治"现金闲置"这个主因。

三项都做完再带 10 万本金跑一遍 Go 回测，看能不能从 **11.3% 拉回 12.5%~13%**。
如果还不行，就说明 10 万本金 + 8 只持仓的组合在 A 股整手约束下只能到这个水平，建议提到 30 万。

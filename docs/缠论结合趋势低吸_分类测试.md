# 缠论结合趋势低吸 · 分类测试与具体用法

> 目标：在**不修改生产代码**的前提下，把缠论按不同用法分类，跑大量对照，找出
> 「怎么用缠论，才能对趋势低吸产生正向作用」。
>
> 测试日期：2026-10-20　范围：**只做回测实验**；生产代码 0 修改；新增的只是两个
> `_test.go` 测试入口（网格 / 明细），默认不跑、不影响任何现有功能。
>
> **后续（第 3 轮）**：又验证了「把买卖时序整个重写、等缠论确认再买卖 / 只按缠论退出 /
> 用触发或候选级信号提前」等 15 种逻辑，结论是**更差**：90% 的建仓单等不到信号，
> 5~10 日内等到卖点的概率只有 2%~3%，详见 [缠论买卖时序重写_测试结果.md](缠论买卖时序重写_测试结果.md)。
> 这佐证了「缠论比趋势低吸晚」是结构性的，不是叠加顺序问题。
>
> 相关文件：[上一轮结果](缠论辅助组合回测_结果.md)｜[网格与安慰剂原始数据](缠论结合趋势低吸_网格与安慰剂结果.json)｜[明细归因原始数据](缠论结合趋势低吸_明细归因.json)｜[方案对比 CSV](缠论结合趋势低吸_方案对比.csv)

## 一、结论（先给答案）

### 1. 正向作用是有的，但用法很窄

在 2 个组合 × 4 个不重叠年度窗口（共 **8 个「组合 × 年度」**）上：

| 用法 | 平均 Δ收益 | 最差窗口 Δ | 平均 Δ回撤 | 最差 Δ回撤 | 正收益窗口 | 回撤不恶化 |
|---|---:|---:|---:|---:|---:|---:|
| **B1：持仓中出现确认三买 → +2 层**（新鲜度 10 日、单股上限 7、关闭缠论卖出） | **+6.82pp** | -2.55pp | +0.09pp | +0.71pp | **5/8** | 7/8 |
| E4：同上，单股上限放宽到 10 | +7.52pp | -2.55pp | +0.09pp | +0.71pp | 5/8 | 7/8 |
| E1：同上，但三买只 +1 层（保守） | +4.09pp | -1.27pp | +0.03pp | +0.27pp | 5/8 | 7/8 |
| D1：三买 +2，但新鲜度收紧到 3 日 | +4.72pp | **-0.29pp** | +0.03pp | +0.21pp | 3/8 | 7/8 |
| A1：只在**计划买入日**遇到二/三买才加层 | +0.90pp | -2.55pp | +0.01pp | +0.11pp | 2/8 | 7/8 |
| B3：只认二买（+1 层） | 0.00pp | 0.00pp | 0.00pp | 0.00pp | 0/8 | 8/8 |
| C1~C4：再加缠论分层卖出 | +6.5~6.6pp | -2.55pp | +0.09pp | +0.71pp | 5/8 | 7/8 |

**推荐用法（B1）**：趋势低吸已经持有的股票，在出现**确认三买**时按 +2 层加仓；
新鲜度 10 个交易日；单股上限 7 层；**不要加缠论卖出**；不要用二买、不要用触发信号。
预期效果：牛市窗口 +9~18pp/年，熊市/震荡窗口 -2.6~0pp，最大回撤基本不变。

### 2. 但它不是「缠论择时 alpha」——安慰剂对照揭示了真相

把同一个规则里的信号**回退 20 个自然日**（规则、层数、频率都相同，只是时间点变旧）：

| 方案（8 个组合年度） | 平均 Δ收益 | 最差窗口 Δ | 平均 Δ回撤 | 最差 Δ回撤 |
|---|---:|---:|---:|---:|
| 真实三买（B1） | +6.82pp | **-2.55pp** | +0.09pp | **+0.71pp** |
| 安慰剂：信号回退 20 日 | **+9.88pp** | -8.91pp | +0.40pp | +1.62pp |
| 安慰剂：信号回退 45 日 | +3.35pp | -3.39pp | -0.39pp | 0.00pp |

- 回退 20 日的「假信号」平均收益**比真实信号还高**，但最差窗口从 -2.55pp 恶化到 -8.91pp。
- 说明：**收益主要来自「加层」这件事本身（提高暴露、改变资金分配），而不是三买的时间点**；
  真实信号在样本内的相对优势只是**尾部更小**，不是均值更高。
- 逐笔归因也支持这一点（见第五节）：多个窗口里，被加层的股票本身是亏的，
  组合却因为「加层占了现金、少做了后面的亏损交易」而变好。

### 3. 明确无效/有害的用法

| 用法 | 结果 | 原因 |
|---|---|---|
| 只在计划买入日加层 | 8 个组合年度平均 +0.90pp，2/8 正 | 计划买入日与新鲜二/三买几乎不重合（约 1/57 个买入行） |
| 只认二买加层 | 0.00pp，完全无变化 | 样本内二买极少在持仓期被确认；单靠二买没有触发 |
| 缠论分层卖出（一/二/三卖） | 比 B1 再低 0.2~0.3pp，最差窗口更差 | 原策略 MA30×0.96 退出更快；一卖/二卖几乎不出现，三卖确认时仓位早没了 |
| 新鲜度放宽到 20 日 | 平均 +6.78pp，但最差 -3.87pp、最差回撤 +3.06pp | 在差窗口把亏损仓位加得更大，属于过拟合 |
| 允许「触发」信号 | 平均 +6.20pp，6/8 正，但平均回撤 +0.37pp、最差 +1.61pp | 触发信号噪声大，回撤变差 |
| 最低综合分 70/80 | 与 B1 完全一致 | 样本内确认三买的综合分本来就都 ≥80，阈值没有筛掉任何信号 |

## 二、测试设计

### 2.1 数据与口径（与生产回测一致）

| 项 | 值 |
|---|---|
| 组合 1（P2） | `pf_1791522403274487100_0002`，主板+创业板，10 层 / 目标 5 只 |
| 组合 2（P1） | `pf_1791522361392503700_0001`，科创板+创业板，10 层 / 目标 5 只 |
| 策略 | `trend_pullback_low_buy`（趋势低吸） |
| 评分 | 本机 `bin/portfolio.db` 副本（2021-10 ~ 2026-10，1216 个交易日） |
| 日线 | 本机数据湖复权日线；缠论与撮合同源 |
| 初始资金 | 100,000 元 |
| 撮合 | T 日收盘出计划、T+1 开盘成交；滑点 0.1%；佣金万 2.5（最低 5 元）；印花税千 1 |
| 层 | 1 层 = 总资产 / 10；低吸基准建仓常见 5 层/只 |
| 信号 | 日线级别；默认只认 **confirmed**；结构矛盾信号剔除 |

### 2.2 四个不重叠年度窗口

| 窗口 | 起止 | 环境特征 |
|---|---|---|
| W1 | 2022-01-12 ~ 2023-10-12 | 熊市/弱震荡 |
| W2 | 2023-10-13 ~ 2024-10-11 | 震荡后急跌 |
| W3 | 2024-10-14 ~ 2025-10-13 | 牛市中的大幅波动 |
| W4 | 2025-10-14 ~ 2026-10-19 | 强趋势 |

### 2.3 分类（19 个方案 + 2 个安慰剂）

| 类别 | 方案 | 说明 |
|---|---|---|
| 基线 | `base` | 现有趋势低吸 |
| A 买入时机 | `A1_plan_buy23` | 只在计划买入日：二买 +1 / 三买 +2 |
| B 持仓加层 | `B1_hold_b3_f10`、`B2_hold_b23_f10`、`B3_hold_b2_f10` | 三买 +2 / 二+三买 / 只二买 |
| D 信号质量 | `D1~D3` 新鲜度 3/5/20；`D4/D5` 分数 70/80；`D6` 允许触发 | 在三买 +2 基础上改一个维度 |
| E 力度 | `E1~E4` 三买 +1/+3、上限 6/10 | 在三买 +2 基础上改层数 |
| C 卖出 | `C1~C4` 三卖 -1/-2/-3、一/二/三卖全开 | 在 B1 基础上叠加分层卖出 |
| P 安慰剂 | `P1/P2` 信号回退 20/45 日 | 同样规则、同样频率，只错开时间 |

### 2.4 判定标准（事前）

- 「正向」：8 个组合年度里平均 Δ收益 > 0，且正收益窗口 ≥ 5/8，且回撤不系统性恶化；
- 「可用」：最差窗口不能超过 -3pp，否则一次坏行情会把多年收益抹掉；
- 「alpha」：必须跑赢安慰剂（或至少在最差窗口/回撤上明显更好），否则只能算「暴露效应」。

## 四、为什么「卖出分层」没用

| 观察 | 数值 |
|---|---|
| 8 个组合年度里，缠论卖出实际减层 | C1~C4 相对 B1 只改变 -0.2~-0.3pp |
| 主要触发类型 | 三卖（一卖/二卖在样本内几乎不出现） |
| 原策略退出 | 「跌破 MA30×0.96 / 结构破坏 / 广度不足」通常更快 |
| 典型反例（P1 W2） | 缠论多卖 2 层后，现金提前释放，反而多做了 2 笔亏损交易，收益 -2.08pp、回撤 +1.31pp（上一轮已记录） |

结论：**在当前日线级别与这套规则下，卖出辅助层没有可用的时间窗口**。
如果一定要用缠论做退出，应该改到 30/60 分钟级别，或把「缠论卖点 OR 原退出」做成并集后再测，
而不是叠加在已经很快的 MA30 退出之上。

## 五、逐笔归因：正向作用到底从哪来？

对 B1 相对基线的已实现盈亏做逐票拆解（金额单位：元）：

| 组合/窗口 | 总 Δ | 被加层股票 Δ | 其余股票 Δ | 被加层股票 | 解读 |
|---|---:|---:|---:|---|---|
| P2 W3 | +2,348 | **-26** | +2,374 | 301316 / 600418 / 603799 | 加层股票没赚钱，收益全靠少做后面的亏损单 |
| P2 W4 | +17,949 | +5,157 | +12,792 | 300672 | 约 29% 来自加层股，71% 来自其它票仓位变大/少做亏损 |
| P1 W1 | +14,677 | +13,016 | +1,661 | 300795 | 约 89% 来自一只被加层的票 |
| P1 W3 | +1,650 | **-4,168** | +5,818 | 8 只 | 加层股票合计亏损，靠少做亏损单翻正 |
| P1 W4 | +7,271 | 0 | +7,271 | 301070 | 加层股未实现盈亏，收益 100% 来自其它票 |
| P1 W2 | **-2,554** | -2,191 | -363 | 300394 / 688100 | 给一笔亏损建仓加了 5 层，放大亏损 |

- **只有 2/6 个可归因窗口**里，被加层股票本身是正贡献；
- 其余窗口，组合变好主要因为「加层占用现金 → 后续少做/晚做了一些交易」；
- 这正是安慰剂（滞后 20 日）也能取得 +9.88pp 的原因：**换一批股票加层，结果同样会出现**，
  只是尾部风险不同。

> 所以，把 B1 描述成「缠论抓三买很准」是不成立的；
> 更准确的描述是：**「在趋势低吸的持仓上，用三买作为加仓触发器，做仓位增强」**。
> 它的收益来自暴露与路径，不是来自预测。

## 六、具体怎么用（推荐配置）

### 6.1 主推：B1「三买加仓增强」

```json
{
  "enable": true,
  "buy2ExtraLayers": 0,
  "buy3ExtraLayers": 2,
  "buyFreshBars": 10,
  "sell1Layers": 0,
  "sell2Layers": 0,
  "sell3Layers": 0,
  "maxLayersPerStock": 7,
  "boostHoldings": true,
  "minSignalScore": 0,
  "allowTriggered": false,
  "allowConflict": false
}
```

Go 调用：

```go
result, err := svc.CreateBacktest(service.BacktestRequest{
    PortfolioID:    "pf_1791522403274487100_0002",
    StartDate:      20241014,
    EndDate:        20261019,
    InitialCapital: 100000,
    ChanlunAssist: &chanlunassist.Config{
        Enable: true, Buy2ExtraLayers: 0, Buy3ExtraLayers: 2,
        BuyFreshBars: 10, MaxLayersPerStock: 7, BoostHoldings: true,
    },
})
```

规则解释：

1. **只认确认三买**：二买单独无效；触发信号噪声大、回撤更差；
2. **新鲜度 10 日**：3 日太严（信号少、平均只有 +4.7pp），20 日会在差窗口放大亏损；
3. **+2 层、单股上限 7**：+1 层偏保守、+3 层与上限 10 的边际收益很小但集中度更高；
4. **关闭缠论卖出**：卖出侧在这个策略上没有可用窗口，反而可能释放现金去做更多亏损交易；
5. **只对趋势低吸**：其它策略的退出节奏不同，不能直接套用。

### 6.2 保守版：E1「三买 +1 层」

把 `buy3ExtraLayers` 改成 1。平均 +4.09pp、最差 -1.27pp、平均回撤 +0.03pp，
适合不能接受单股 7 层（70% 仓位）的人。

### 6.3 明确不要用

- `A1`（只在计划买入日加层）：命中率约 1/57，等于没开；
- `B3`（只认二买）：样本内没有触发；
- `C1~C4`（缠论卖出分层）：无正向作用，弱市更差；
- `D3`（新鲜度 20）、`D6`（允许触发）：平均看似不差，但最差窗口/回撤明显恶化。

## 七、限制与风险（必须一起读）

1. **不是稳定 alpha**：安慰剂回退 20 日平均收益更高；真实信号只在尾部更小。
   这说明收益主要来自「加层/资金再分配」，换一段行情可能消失。
2. **样本小**：2 个组合 × 4 个年度 = 8 个组合年度，约 100+ 笔卖出；
   没有做统计显著性检验，不宣称「显著」。
3. **多重比较/过拟合风险**：本轮试了 19 个方案，虽然事前按类别设计，
   但「选平均最高的」仍会带来赢家诅咒。B1 不是平均最高（E4 更高），
   选它是因为上限 7 更保守；这个选择本身也是事后判断。
4. **集中度**：单股最多 7 层（约 70% 仓位）；P1 W1 的 +14.68pp 里约 89% 来自一只票（300795）。
5. **回测成交约束不完整**：未模拟涨跌停买不进/卖不出、停牌、流动性冲击。
6. **现金约束而非层预算**：加层会挤占后续建仓，收益里混合了「信号」与「再分配」，
   当前实现无法完全分离。
7. **缠论实现是项目内的规则化版本**：结论只对该实现、日线级别成立。

# 纯缠论策略 · 多市场组合测试

> 策略定义：**所有买卖信号只来自缠论**，叠加一组基本面前置条件：
> 总市值 100 亿~2000 亿、PE 10~300、PB 2~10、ROE>8%、排除 ST、
> 最近一期单季净利润同比 >15%。
>
> 市场组合：主板 / 创业板 / 科创板 / 主板+创业板 / 创业板+科创板 / 全部。
>
> 测试日期：2026-10-20　范围：**只做回测实验**；生产代码 0 修改；
> 新增的只有测试文件 `internal/service/chanlun_pure_strategy_test.go`。
>
> 数据：[结果 JSON](纯缠论策略_结果.json)｜[方案对比 CSV](纯缠论策略_方案对比.csv)

---

## 一、结论

**按这套定义，纯缠论策略在日线级别不能稳定盈利；新鲜度会显著改变结果，但改变不了熊市亏损。**

- **信号被基本面过滤砍到极少**：牛市窗口 7,676 个买信号里只有 **239 个（3.1%）** 通过全部条件；
  熊市窗口 6,191 个里只有 **297 个（4.8%）**。
- **组合只剩 2~10 笔交易**，5 个仓位经常一次打满（平均仓位 90%+），
  等于把资金押在少数几只票上，回撤 25%~52%。
- **牛市只有“全部市场 + 二/三买 + 三卖”略微为正**：
  +12.51%（新鲜度 0 时；跑赢沪深 300 约 7.13pp），但最大回撤 25.04%、只有 7 次建仓/2 次卖出，
  样本太小，不能当成稳定能力。
- **熊市全部为负**：主板 -25.40%、创业板 -31.39%、科创板 -18.86%、
  主板+创业板 -30.35%、创业板+科创板 -25.19%、全部 -30.71%，
  对比沪深 300 约 -19.78%，**普遍跑输**，最大回撤 32%~45%。
- 纯缠论卖出信号太稀少：两年只有 1~5 次卖出，大部分持仓**一直拿到期末**，
  没有止损/风控，回撤自然大。

### 1.1 重要修正：上一版没有测信号新鲜度

上一版纯缠论测试只允许**确认日当天买入**（新鲜度 = 0），信号错过就作废。补测 3/5/10/20 日后：

- 牛市「全部市场 + 一/二/三买 + 新鲜度 10 日」：**+30.77% / 回撤 27.54%**
  （新鲜度 0 时只有 +10.83%）；
- 牛市「只三买」：新鲜度 0 时 -19.08%，新鲜度 10 日变成 **+13.49%**；
- 熊市「全部市场 + 二/三买」：从 -30.71% 改善到 **-22.96%**，但**仍然为负**；
- 所以结论要从“完全不成立”修正为：**牛市样本里可以做出正收益，但没有熊市保护，跨窗口不稳定。**

一句话：**新鲜度是纯缠论策略的一阶变量，必须测；但补上新鲜度后，它仍然不是一个可稳定盈利的策略。**

### 1.2 多周期：大周期定方向、小周期定买卖点（重要）

用日线聚合出周线/月线，`BuildReplay` 逐周/逐月取“当时”的缠论状态做方向，日线仍负责买卖点：

- **把大周期当“一票否决”买点，效果不好**：
  - 周线趋势向上只占 27%（牛市）/15%（熊市），会错过大部分行情；
  - 周线“最近买卖点定多空”能显著改善熊市（全部市场 -22.96% → **-3.34%**，回撤 41.08% → 19.50%），
    但牛市被砍到 **-33.50%**（周线卖点太频繁，方向频繁翻空）；
  - 月线趋势向上只占 1%/0%，月线买卖点只有 29 个点，基本无法用（数据/定义都太稀疏）。
- **把大周期当“仓位档位”才有效**：周线方向向上 → 满仓（2 层/只），否则半仓（1 层/只）。
  - 牛市：+11.16% / 回撤 23.29%（全仓日线基准 +16.50% / 26.02%）；
  - 熊市：**-11.47% / 回撤 22.93%**（全仓日线基准 -22.96% / 41.08%）；
  - 一/二/三买：牛市 +17.90%、熊市 -11.47%，是**唯一同时做到“牛市仍正、熊市亏损减半、回撤减半”**的组合。

**结论：大周期应该用来定“仓位/风险预算”，而不是否决日线买点。** 这版多周期仓位方案仍不能把熊市做成正收益，但它是目前最接近“大周期定方向、小周期定买卖点”的可用形态。

## 二、数据与口径

### 2.1 信号

- 买入：日线缠论**确认**一买 / 二买 / 三买（测试 3 组：只三买、二+三买、一+二+三买）；
- 买入新鲜度：确认后 N 个交易日内仍可买（本轮测 **0 / 3 / 5 / 10 / 20** 日；0 = 只在确认日当天）；
- 卖出：日线缠论**确认**一卖 / 二卖 / 三卖（测试 2 组：只三卖、一+二+三卖）；
- 信号在 T 日收盘确认，T+1 开盘成交；不做任何均线/止损/止盈（保持“纯缠论”）。

### 2.2 基本面前置条件（按信号日时点）

| 条件 | 口径 |
|---|---|
| 总市值 | 收盘价 × 总股本（`share_structure` 取信号日前最近一次变更）∈ [100 亿, 2000 亿] |
| PE | 总市值 ÷ 最近 4 个单季净利润之和 ∈ [10, 300] |
| PB | 总市值 ÷ 最近一期净资产 ∈ [2, 10] |
| ROE | TTM 净利润 ÷ 净资产 × 100 > 8 |
| ST | 名称含 `ST` / `退`（当前名称近似） |
| 季报增长 | 最近一期已公告财报的单季净利润同比 > 15% |

> **为什么不用 `valuation_metrics`**：本机该表近期只有约 **237 只/日** 有数据（不是全市场），
> 直接筛会系统性地漏掉大多数股票。因此改用「股本 × 收盘价 + 财报」逐日推算，
> 并用**公告日**做时点门控。代价是股本变更日没有公告日字段，用变更日近似。

### 2.3 回测设置

| 项 | 值 |
|---|---|
| 组合 | 5 只 × 2 层（另测 10 只 × 1 层），总 10 层 |
| 初始资金 | 1,000,000 元 |
| 成交 | T+1 开盘；滑点 0.1%；佣金万 2.5（最低 5 元）；印花税千 1 |

## 三、过滤漏斗：信号是怎么被砍没的

每个条件单独通过多少条买信号（非累计；`all` 为全部条件同时通过）：

| 条件 | 窗口 A（牛市） | 窗口 B（含熊市） |
|---|---:|---:|
| 缠论买信号 | 7,676 | 6,191 |
| 能取到基本面（收盘/股本/净资产/TTM） | 4,803 | 3,924 |
| 总市值 100~2000 亿 | 2,875 | 2,183 |
| PE 10~300 | 3,406 | 3,082 |
| PB 2~10 | 2,539 | 2,159 |
| ROE > 8% | 1,862 | 2,029 |
| 单季同比 > 15% | 2,055 | 1,815 |
| 非 ST | 4,733 | 3,847 |
| **全部通过** | **239（3.1%）** | **297（4.8%）** |

- **PB 2~10** 和 **单季同比 >15%** 是最大的两个收缩项；
- 条件之间高度相关（高 ROE 往往高 PB、高 PE），叠加后只剩 3%~5%；
- 再叠加“只在确认日买、最多 5 只”，两年只能建仓 6~10 次。

## 五、多周期：大周期定方向、小周期定买卖点

### 5.1 方向是怎么算的

- 日线聚合成**周线/月线**（OHLCV 标准聚合，日期取周期最后一个交易日）；
- 用 `chanlun.BuildReplay` 对周线/月线**逐段重算**，只取“该周期结束当时”能确认的状态；
- 日线日期只使用**严格早于当日**的周/月状态（避免用未走完的周期）；
- 两种方向定义：
  1. **趋势方向**：周/月 `Trend.Type == 上涨`（或反转确认向上）；
  2. **买卖点方向**：周/月最近一个确认买点之后为多，卖点之后为空。

方向本身的分布（全部 5227 只，两个窗口）：

| 方向来源 | 牛市 | 熊市 |
|---|---:|---:|
| 周线趋势向上 | 27% 的周状态 | 15% |
| 月线趋势向上 | 1% | 0% |
| 周线买卖点：多头 | 62% | 33% |
| 月线买卖点 | 只有 29 个点 | 无 |

> 月线方向基本不可用：月线只有约 56 根（1700 天预热），`Analyze` 的中枢/走势要求导致状态和信号都极稀疏。
> 周线趋势向上只占 15%~27%，所以“周线必须上涨才买”会天然错过大部分行情。

### 5.2 把大周期当“一票否决”：效果不好

全部市场、二/三买、5 只 × 2 层、新鲜度 10：

| 方案 | 牛市收益/回撤 | 熊市收益/回撤 |
|---|---:|---:|
| 不加方向（日线全仓） | **+16.50% / 26.02%** | -22.96% / 41.08% |
| 周线趋势向上才买 | -4.39% / 37.59% | -28.48% / 42.91% |
| 周线非下跌才买 | +4.48% / 26.26% | -26.69% / 41.48% |
| 周线最近买点才做多 | -33.50% / 33.91% | **-3.34% / 19.50%** |
| 月线趋势向上才买 | -7.93% / 8.90%（仅 2 次建仓） | 0%（无建仓） |

- **周线趋势向上**：牛市被砍掉大半，熊市也没改善 → 不成立；
- **周线买卖点方向**：熊市极好（-3.34%，回撤 19.50%），但牛市 -33.50% ——
  周线卖点太频繁，方向频繁翻空，把牛市也过滤掉了；
- **月线方向**：几乎不产生状态/信号，直接不可用。

### 5.3 把大周期当“仓位档位”：目前最好的多周期形态

规则：**周线方向向上 → 2 层/只；否则 1 层/只**（不否决日线买点）。

| 方案 | 牛市收益/回撤 | 熊市收益/回撤 |
|---|---:|---:|
| 日线全仓（2 层） | +16.50% / 26.02% | -22.96% / 41.08% |
| 周线趋势向上满仓、否则半仓 | +9.00% / 26.16% | -19.20% / 33.90% |
| **周线买卖点向上满仓、否则半仓** | **+11.16% / 23.29%** | **-11.47% / 22.93%** |
| 月线趋势向上满仓、否则半仓 | +11.16% / 23.29% | -11.47% / 22.93%（月线几乎不向上 → 实际一直半仓） |
| 一/二/三买 + 周线买卖点半仓 | **+17.90% / 24.70%** | **-11.47% / 22.93%** |

各市场组合（周线买卖点、半仓）：

| 市场 | 牛市收益/回撤 | 熊市收益/回撤 |
|---|---:|---:|
| 主板 | -6.85% / 20.63% | -12.83% / 20.98% |
| 创业板 | -22.65% / 34.06% | -13.58% / 23.12% |
| 科创板 | -1.96% / 21.50% | **-9.22% / 16.70%** |
| 主板+创业板 | -7.46% / 21.75% | -9.33% / 21.09% |
| 创业板+科创板 | +3.89% / 23.21% | -14.23% / 24.77% |
| **全部** | **+11.16% / 23.29%** | **-11.47% / 22.93%** |

**这是本轮唯一同时做到“牛市仍为正、熊市亏损减半、回撤减半”的多周期方案。**
但它仍然不能把熊市做成正收益，也不能改变“少数持仓、集中度高”的本质。

### 5.4 多周期应该怎么用

- **大周期定方向 = 定仓位/风险预算**，不是“没向上就不买”：
  - 周线多头：2 层/只；
  - 周线非多头：1 层/只（或 0.5 倍风险预算）；
- **小周期定买卖点**：日线确认买点负责入场，日线卖点负责退出；
- **月线目前不可用**：数据长度/信号稀疏，等月线有足够历史后再测；
- 周线方向用 `BuildReplay` 逐周重算，**不能**用“最后一周的状态”回填历史。

---

## 六、为什么这条路走不通

1. **信号频率与过滤强度不匹配**：日线缠论买点本来就不多（两年 7,676 个，全市场约 16 个/日），
   再叠加 6 个基本面条件，只剩 3%~5%；而组合一次要 5 只，几天就把仓位打满。
2. **纯缠论卖出太慢**：两年只有 1~5 次卖出，持仓平均要拿很久；
   没有止损，遇到熊市就是“满仓扛”。
3. **无法分散**：通过过滤的票集中在少数行业/风格（高 ROE、中高 PB、季报高增长），
   5 只票的相关性很高，回撤 25%~52%。
4. **基本面过滤是“事后好看”**：高 ROE + PB 2~10 + 单季 >15% 的组合，
   在 A 股里天然偏向“已经被市场充分定价”的核心资产，缠论买点又要求回抽确认，
   结果买在高位、卖点迟迟不来。

---

## 七、如果还要继续，建议先动这三处

1. **多周期先做“仓位档位”，不要做“一票否决”**：
   - 周线买卖点向上 → 2 层/只，否则 1 层/只；
   - 熊市回撤从 41% 降到 23%，牛市仍 +11.16%；这是本轮最值得保留的改进。
2. **先定新鲜度，再谈放宽过滤**：
   - 本次牛市最好的是 10 日，但主板在 3 日反而更差；按市场分别定，不要一律 10 日；
   - 新鲜度让“当天没仓位/没现金”的信号不再作废，是比放宽基本面更直接的改善项。
2. **放宽过滤，保证信号量**：
   - PB 2~10 是最大收缩项，可先放到 1~15；
   - 单季同比 >15% 可改成“最近 2 个季度至少 1 次 >15%”或 >0%；
   - PE 上限 300 基本不卡，下限 10 可以保留（排除亏损/极低估值陷阱）。
   目标：每个市场组合每年至少 20~30 个可买信号，否则无法形成 5 只组合。
3. **给纯缠论加“退出兜底”**：
   - 只靠日线卖点，两年只有 1~5 次；可加“买入后 N 日未创新高则退出”或
     “跌破买点保护位退出”（这已经不是纯缠论，但能控制回撤）；
   - 或改到 30/60 分钟级别，让卖点更及时（需要分钟数据与代码支持）。
4. **按市场分别定参数**：
   - 科创板在熊市表现最好（-18.86%，唯一接近基准），但样本只有 36 个过滤后信号；
   - 创业板最差（-31.39%，回撤 45.31%），不适合这套“高 ROE + 中高 PB”的选股；
   - “全部市场”在牛市最好、熊市最差，说明它只是放大了 beta。

---

## 八、限制

1. **估值是推算的**：用股本 × 收盘价 + 财报，而不是现成估值表；
   `valuation_metrics` 本机只有约 237 只/日，覆盖不足。
2. **股本变更日用 change_date 近似可用日**，理论上可能比公告早几天，存在轻微前视；
3. **ST 用当前名称近似**，历史 ST 状态没有逐日门控；
4. **TTM 净利润**用最近 4 个已公告单季净利润相加；缺失季度会导致该股被过滤；
5. **纯缠论无风控**：没有止损/止盈/仓位上限之外的保护，回撤是策略定义的一部分；
6. **样本小**：两个窗口、每个组合 2~10 笔交易，不能做统计显著性结论；
7. **未模拟涨跌停/停牌/流动性**，极端行情下结果偏乐观；
8. **多周期有额外近似**：月线只有约 56 根（1700 天预热），月线方向/信号极稀疏、基本不可用；
   周线方向每 2 周取一次状态（`ReplayStep=2`），最多滞后 2 周；只看“已完成”的周/月，不碰未走完的周期。

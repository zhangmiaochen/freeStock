# A 股多期限性价比评估功能开发方案

> 本文是**功能设计基准**（需求方原始方案的落地版）。
> 与原方案逐条对应，但凡涉及本机数据实际能力的地方，都按**实测**改写并标注数据来源。
> 实施进度与偏差记录在 `docs/A股多期限性价比评估开发计划.md`。

---

## 一、项目目标

在现有 FreeStock 中新增**「A 股多期限性价比评估」**功能：利用已有的行情、财务、行业分类、历史估值与外部数据，
对 A 股个股与指数做系统性评估，识别**不同投资期限下风险收益匹配更好**的标的。

不以短期涨跌幅作为核心判断依据，而是从公司基本面、成长能力、行业估值、个股相对估值、安全边际、
未来收益空间与潜在风险出发，输出：

| 输出项 | 说明 |
|---|---|
| 个股多期限性价比评分 | 1 / 3 / 6 / 12 / 36 个月，**逐期限独立计算** |
| 指数多期限性价比评分 | 独立模型，不是成分股评分加权 |
| 排名 | 全市场、行业内、指数与指定证券池，按期限独立排名 |
| 合理价值区间与安全边际 | 悲观 / 基准 / 乐观三情景 |
| 成长能力、成长质量、盈利质量 | 三个**分开**评价的维度 |
| 预期收益、悲观损失、风险收益匹配 | 按情景概率加权 |
| 结论、关键依据、主要风险、数据可信度 | 每个评分可追溯到指标与时点 |

**五档期限**：1 个月（约 21 交易日）、3 个月（约 63）、6 个月（约 126）、12 个月（约 252）、36 个月（约 756）。
五档必须走**不同的预测与估值参数**，禁止复制同一个分数。

### 2.2 三条必须写进设计的硬约束

**约束 1：历史估值分位不能直接用现成数据。**
`valuation_metrics` 只有 5 天，行业归属只有 5 天。所以：

- **个股自身历史估值分位**不能读现成 PE/PB 序列 —— 必须**自己重建**：
  `历史市值 = 历史股本 × 当日价格`，`历史 PE = 历史市值 ÷ 当时已披露的 TTM 净利润`，
  `历史 PB = 历史市值 ÷ 当时已披露的归母净资产`。
  重建区间取 **2022-01-01 起**（`daily_bars` 每日约 5000 只的起点），样本约 1150 个交易日、近 5 年。
- 重建的 PE/PB 与供应商口径会有差异，**必须在界面上标明口径**
  （"自建 TTM 重建" vs "供应商报告值"），并把两者并列展示做交叉检查。

**约束 2：行业历史估值分位只能在有限窗口内做时点正确。**
`industry_members` 只有 5 个快照，`eastmoney` 体系。因此：

- 行业**当前**估值（PE/PB/PS 的加权/中位/分位）可以做，成分取最新快照；
- 行业**历史**估值序列只能在有快照的窗口内做时点正确重建；
- 2026-10 之前的历史回测，行业归属只能**用当前归属近似**，
  结论里必须标注"存在行业归属前视偏差"。这一点在验收标准 9 上降级说明，不假装满足。

**约束 3：财务数据是年内累计，必须转单季再算 TTM。**
实测（600519）：2024Q1 营收 464.85 亿、Q2 累计 834.51 亿、Q3 累计 1231.23 亿、Q4 累计 1741.44 亿。
所以 `单季 = 本报告期累计 − 上一报告期累计`（Q1 直接取累计），`TTM = 最近 4 个单季之和`。
直接对累计值做同比会**系统性高估**增长率（Q2 对 Q2 累计看着正常，Q3 亦然，但滚动 TTM 会失真）。

### 2.3 复权口径（本项目踩过坑的地方）

数据湖 `daily_bars` 是**不复权**行情。实测：002594 在 2025-07-29 因 1:3 送转由 337.00 直接变成 111.42。
未复权价算出来的 MA250 仍是 ~310，`ma250/close ≈ 2.9`。后果：

- 除权日 `close < MA30×0.96` 发生率 **44.4%**，平时只有 **29.8%**（1.49 倍）→ 大量"假破位"；
- 送转股在其后最长一年内通过不了任何 `close > MA` 条件 → 被错误排除出候选池（实测候选池 −12.3%）。

**本功能对复权的三条规则（必须严格遵守）：**

| 用途 | 口径 | 理由 |
|---|---|---|
| 收益率、波动、回撤、区间涨幅、情景收益 | **后复权 hfq**（`daily_bars × F(t)`） | 尺度无关且历史值永不改变 → 可复现、可回测 |
| 历史市值 / PE / PB / PS | **不复权原始价 × 当期股本** | 复权只是记账口径，市值必须用真实成交价 |
| 成交量 / 成交额 | **始终原始** | 那是真实成交的钱；F 是每股常数，放大成交额会让排序失真 |

实现上直接复用 `cnlake.AdjustBars` / `cnlake.AdjScale`（`internal/cnlake/adjfactor.go`），
不新造复权逻辑。**前复权锚定最新因子**，历史行会随新除权重算，所以只用于展示、不用于回测。

## 三、总体业务流程

```
① 数据准备与有效性校验  →  DataSnapshot（评估日 / 数据截止时点 / 模型版本 / 覆盖率）
② 基本面与成长能力      →  GrowthProfile（成长能力 + 成长质量，分开）
③ 个股自身历史估值      →  SelfValuation（自建 PE/PB/PS 序列 + 分位）
④ 行业整体估值          →  IndustryValuation（加权 / 中位 / 分位，三者分开保留）
⑤ 个股相对行业与同行    →  RelativeValuation（折溢价 + 分位 + 可比公司）
⑥ 成长调整后的合理价值  →  FairValue（三情景 + 合理价值区间 + 安全边际）
⑦ 多期限预期收益与风险  →  HorizonOutlook × 5（1/3/6/12/36 各自独立）
⑧ 综合评分与风险约束    →  Score + Rating + RiskFlags + Confidence
⑨ 排名                  →  全市场 / 行业内 / 指数 / 证券池，按期限独立
⑩ 展示与追溯            →  总览 / 多期限对比 / 个股 / 行业 / 指数 / 依据追溯
```

**去重原则（原方案 §7.1 明确要求）**：同一份信息只能进一个计分格。
本方案用**一张显式的去重表**约束，见 §8.2。

## 四、阶段①：数据准备与有效性校验

### 4.1 DataSnapshot

所有结果绑定 `(EvalDate, DataCutoffAt, ModelVersion)`：

- `EvalDate`：评估基准交易日（YYYYMMDD）。
- `DataCutoffAt`：数据截止时点（行情到当日收盘、财务到 `announce_date <= EvalDate`）。
- `ModelVersion`：模型版本号常量，权重/阈值一变就升版本，历史结果不覆盖。

### 4.2 时点正确（point-in-time）

- **财务**：只取 `announce_date <= EvalDate` 的报告期。`announce_date` 在本机 100% 有值
  （实测 2025Q4：161676 行全部非空），所以这条门控是硬的。
- **财务预测与已披露分离**：`analyst_consensus` 属预测，单独字段、单独标注，不混入"已披露"。
- **停牌 / ST / 退市**：用 `trading_status` 月度快照 + `daily_bars` 是否有当日行双重判断。
- **股本**：按 `change_date` 取"截至 EvalDate 生效"的值（`share_structure` 覆盖 2001 起）。

### 4.3 有效性校验与降级

| 检查 | 处置 |
|---|---|
| 行情缺失 / 区间不足（不足 252 日 → 无法算 12 个月以上的波动与回撤） | 降低置信度 |
| 财报缺关键科目（营收 / 净利润 / 净资产 / 经营现金流） | 该维度标"不可评" |
| 亏损公司（TTM 净利润 ≤ 0） | PE 不适用 → 切 PS / PB / EV/EBITDA，并记录切换原因 |
| 金融股（银行/保险/券商） | 第一版**排除**于估值评分之外，只给成长与质量 |
| 一次性损益 / 非经常性收益 | `net_profit − net_profit_deducted` 差值占比 > 阈值 → 成长质量降级 |
| 异常值 | 分位数 1%/99% 缩尾（winsorize），不做删除 |
| 行业样本 < 5 只 | 行业中位数不可靠 → 回退到全市场分位，并标注 |

**关键数据缺失或模型不适用时，输出"暂无法可靠评估"，不强行给正常评级。**

## 五、阶段②：基本面与成长能力

### 5.1 成长能力（Growth Ability）

| 维度 | 指标（全部来自 `financial_statement_items`） |
|---|---|
| 收入成长 | `revenue` 单季同比、近 3 年 CAGR、近 5 年 CAGR |
| 盈利成长 | `net_profit`（归母）、`net_profit_deducted`（扣非）、`operating_profit` 单季同比与 TTM 同比 |
| 现金流成长 | `net_cash_operate`、自由现金流 `= net_cash_operate − capex` |
| 成长持续性 | 多年度增长符号一致性、增速标准差、`revenue_yoy`/`net_profit_yoy` 的波动 |
| 资本投入效率 | `roe`、增量 ROIC 近似、`capex / net_cash_operate` |

**不能只依据单年增长率判断成长能力。** 必须识别并在结论里点名的四种情形：

- **低基数**：上年同期增速极低或为负 → 本期高增速没有信息量；
- **并购扩张**：营收增速 ≫ 经营现金流增速且总资产跳升；
- **周期反弹**：行业整体同步反转（用行业中位数增速做对照）；
- **一次性收益**：`net_profit − net_profit_deducted` 贡献占比高。

### 5.2 成长质量（Growth Quality）—— 与成长能力**分开**评分

| 判据 | 计算 |
|---|---|
| 收入增长是否来自主营 | `operating_profit / total_profit` 是否稳定，`revenue` 与 `operating_cost` 同向 |
| 利润增长是否可持续 | 扣非占比、单季利润的离散度、是否连续 4 季环比恶化 |
| 利润是否有现金流支持 | `net_cash_operate / net_profit`（现金含量），连续两年 < 0.7 → 降级 |
| 增长是否依赖过度负债 | `total_liabilities / total_assets` 变化、`net_cash_finance` 是否持续为正（持续融资） |
| 新增资本能否获得合理回报 | 增量投入资本回报 = ΔNOPAT / Δ投入资本，与 `roe` 同向且不低于门槛 |
| 预测与历史能力是否匹配 | 一致预期增速 vs 历史 3 年实际增速的差 |

**规则**：高增长但现金流持续恶化 / 扣非占比低 / 依赖过度负债 → 成长质量降级，
并在最终评级上施加风险约束（§8.3），**不允许**只靠高增速拿高分。

### 5.3 行业成长背景

- 个股成长能力 / 成长质量在行业内的分位；
- 行业整体增速（行业中位数 `revenue`/`net_profit` 单季同比）；
- 行业所处阶段判定：成长 / 成熟 / 衰退 / 周期波动（用行业增速的**均值与波动**二维判定）；
- **行业景气度只作为基本面依据，不等同于个股投资价值**（防止"行业好 → 直接加分"）。

## 六、阶段③④⑤：个股与行业联合估值（核心模块）

原方案要求四层 + 交叉验证。四层是**串联**关系：自身分位 → 行业环境 → 相对同行 → 成长调整。

### 6.1 第一层：个股自身历史估值

- 指标：PE_TTM、PB、PS_TTM、EV/EBITDA、股息率。按行业与盈利状态**只取适用的**（§6.5）。
- 历史序列：**自建重建**（§2.2 约束 1），起点 2022-01-01，向前取 3 年 / 5 年两个窗口。
- 输出：当前值、历史中位数、历史区间（10/25/50/75/90 分位）、当前分位。
- 归因：分位变化有多少由**盈利变化**、多少由**价格变化**解释（
  `PE = P / E`，所以 `ΔlnPE = ΔlnP − ΔlnE`，可直接分解）。
- **结构性变化降权**：若商业模式/盈利能力/成长阶段已变（例如 ROE 中枢移动超过阈值、
  或近 3 年增速中枢与 5 年中枢背离），历史分位权重下调，并在结论里说明。

> **常见误用（本方案明确禁止）**：把"历史分位低"直接当作"合理价值低"。
> 历史分位只说明**在自身历史中的相对位置**，不构成合理价值。

### 6.2 第二层：行业整体估值

- **统计口径三者分开保留，不合并成一个指标**：
  - 行业**加权** PE/PB（用自由流通市值加权，接近行业指数口径）；
  - 行业**中位数** PE/PB（抗极端值）；
  - 行业**历史分位**（行业自身序列的分位）。
- 亏损公司处理：PE 聚合时剔除 TTM 净利润 ≤ 0 的公司，并**单独给出亏损公司占比**；
  占比过高时行业 PE 不可信，改用 PB / PS 并标注。
- 盈利结构：行业整体 ROE、`net_profit` 增速、`gross_margin` 中位数。
- **集中度检查**：前 3 大权重公司对行业估值的贡献占比，超过阈值时提示
  "行业估值受少数高权重公司影响"，同时给出剔除前 3 后的中位数。
- 周期位置：行业 PE 与行业 ROE 的历史分位**配对**判断（PE 低 + ROE 高位 = 周期顶部陷阱；
  PE 高 + ROE 低位 = 周期底部）。

### 6.3 第三层：个股相对行业与同行

- 个股 PE/PB 与行业加权、行业中位数、行业分位的差异（绝对差 + 相对折溢价率）。
- 个股在同行中的估值分位（同行定义见下）。
- 同时给出**基本面差异**：成长能力分、成长质量分、ROE、资产负债率、盈利波动。
- **同行可比公司筛选**（不能只因同属一个宽泛行业就比较）：
  1. 同一 `eastmoney` 行业（三级，缺则二级）；
  2. 剔除 PE 不可用（亏损）、剔除市值小于个股 1/10 或大于 10 倍；
  3. 按成长属性分层：增速分位相近（同一档）；
  4. 财务特征：资产负债率差距在阈值内；
  5. 不足 5 只时逐级放宽，最终回退行业全体，并标注"可比性下降"。
- 判定矩阵（原方案 §5.3 的逻辑，落成**显式四象限**）：

| 估值 vs 行业 | 成长/质量 vs 行业 | 结论倾向 |
|---|---|---|
| 低 | 优 | 估值折价机会（**唯一可以给高性价比的信号组合**） |
| 低 | 劣 | 合理折价 **或** 价值陷阱 → 检查成长趋势与现金流质量再定 |
| 高 | 优 | 允许合理溢价，但必须检验溢价幅度（PEG / PB-ROE 合理性） |
| 高 | 劣 | 提高估值风险评价 |
| **个股与行业都低** | 任意 | **不能直接判高性价比** → 必须看行业周期位置与未来成长 |

### 6.4 第四层：成长调整后的合理价值

核心问题：**当前估值是否已经反映了未来可能实现的成长？溢价是否有基本面支撑？**

- 预测明细分档（与 §7 的五档期限匹配）：

| 期限 | 收入/利润预测方式 | 估值锚 |
|---|---|---|
| 1 个月 | 用最近 1~2 季已披露趋势外推，不加新假设 | 当前估值区间（自身 + 行业） |
| 3 个月 | 最近 2 季趋势 + 已公布的预约披露 | 当前估值区间 + 行业估值环境变化 |
| 6 个月 | 未来 2 个季度：淡/旺季季节性 + 趋势 | 行业相对估值修复空间 |
| 12 个月 | 未来 4 个季度：分季度预测（含季节性） | 合理 PE（成长调整后） |
| 36 个月 | 3 年 CAGR 假设 + 利润率路径 + 终值 | 稳态 PE / PB-ROE / 简化 DCF |

- 利润率路径：`gross_margin`、`net_margin` 的历史中枢与趋势，向中枢回归（不是线性外推）。
- 再投资与资本回报：`capex / revenue`，增量 ROIC 与 WACC 的比较（WACC 用可配置常数，默认 8%）。
- **反向 DCF（隐含预期检查）**：用当前价格反解市场隐含的 3 年增速，
  与公司历史实际增速、行业中位数对比，得出"市场预期偏高 / 合理 / 偏低"。
  这是防"乐观假设堆出虚高评分"的关键闸门。
- **禁止**：把高增长率直接乘成高估值；把行业平均估值不加调整套用到所有公司。

### 6.5 第五层：多模型交叉验证

| 方法 | 适用条件（自动判定，可配置） |
|---|---|
| PE | TTM 净利润 > 0，且近 8 季净利润波动率 < 阈值 |
| PB | `total_equity` > 0，且 ROE 有参考价值（非重资产轻资产极端） |
| PS | 净利润不稳定/为负，但收入规模与质量有意义 |
| EV/EBITDA | EBITDA = `operating_profit` + 折旧摊销近似 > 0，资本结构差异大 |
| DCF | 经营现金流为正、`net_cash_operate` 波动率低、长期可预测 |
| PEG / PB-ROE | 仅作**辅助**判断，不单独定价值 |
| 周期调整估值 | 行业判定为"周期波动"时，用 TTM 与 5 年平均双口径（类似 CAPE 思路） |

- 相对估值（判断市场定价位置）与绝对估值（检验内在价值）**相互校验**：
  结果明显冲突（区间不重叠）时 → **解释原因 + 降低置信度**，**不机械取平均**。
- 输出：每种适用方法的价值估计、采用与否、权重依据、冲突程度。

### 6.6 合理价值区间与安全边际

对每个期限输出三情景：

```
悲观价值 = f(悲观增速, 悲观利润率, 悲观估值倍数)
基准价值 = f(基准假设...)
乐观价值 = f(乐观假设...)
合理价值区间 = [悲观价值, 乐观价值]，基准价值为中枢
```

- **安全边际** =（基准合理价值 − 当前价格）÷ 基准合理价值
- **潜在收益** =（目标价值 − 当前价格）÷ 当前价格

两者口径不同，**分别展示、不得混用**（原方案 §5.6 明确要求）。

- 置信度由以下决定并输出为 0~100 分 + 等级：
  - 估值区间宽度（越宽越低）；
  - 关键假设的敏感度（对增速 ±1pct 的价值变化）；
  - 数据覆盖率（财务科目、行情长度、行业样本数）；
  - 多方法冲突程度。

## 七、阶段⑦：多期限风险收益评估

### 7.1 五档期限的侧重点（独立参数）

| 期限 | 独立关注点 | 估值锚 | 风险主导项 |
|---|---|---|---|
| 1 个月 | 当前估值位置、近期已知风险、盈利预期变化、不确定性 | 当日自身与行业估值分位 | 波动率、事件风险、流动性 |
| 3 个月 | 近期基本面变化、行业估值环境、盈利预期变化 | 短窗口估值均值回归 | 估值调整风险、季报风险 |
| 6 个月 | 盈利兑现、成长预期变化、行业相对估值、估值修复 | 合理 PE × 滚动预测 | 成长兑现不及预期 |
| 12 个月 | 未来一年盈利增长、合理估值变化、分红、潜在风险 | 合理 PE × 未来 4 季 | 盈利下修、估值下修双击 |
| 36 个月 | 长期成长空间、竞争优势、资本回报、现金流、终值 | 稳态 PE / PB-ROE / DCF | 终值假设、竞争格局、结构性衰退 |

**硬约束**：长期合理价值不能直接当短期目标价值；短期市场估值不能简单外推到长期。
实现上，`HorizonParams` 是**一张按期限索引的配置表**（增速映射系数、估值回归速度、
波动率年化系数、分红计入方式），五档参数不同 —— 这是"不允许复制同一评分"的机制保证。

### 7.2 情景分析

每档期限至少三情景，且各情景**明确关键假设、概率、收益**：

```
情景收益 = (目标价格 − 当前价格) / 当前价格        // 含分红则加上期间股息
预期收益 = Σ(概率ᵢ × 情景收益ᵢ)                    // 概率加权
悲观损失 = |min(情景收益)| or 悲观情景收益（取负值展示）
风险收益比 = 预期收益 / 悲观损失绝对值
```

- 概率随期限变化：短期限情景概率更接近中性分布，长期限的乐观/悲观尾部概率更大（可配置）。
- **乐观依赖度检查**：计算"若乐观情景不发生，评分下降多少"。
  若评分高度依赖乐观情景（例如基准不足以支撑评级），强制降级并输出风险旗标。

### 7.3 分红

`corporate_actions` 提供 `cash_dividend`（每股派息，ex_date 2023~2026）。
各期限把**评估日之后、期限之内**的除权日现金流计入收益：
股息率 = Σ(期间每股派息) ÷ 当前价格。2023 年之前无明细 → 只用 2023 起的已知派息，并标注覆盖窗口。

## 八、阶段⑧：综合评分与风险约束

### 8.1 九个评分维度（对应原方案 §7.1）

1. 个股自身估值合理性（③）
2. 行业整体估值环境（④）
3. 个股相对同行的估值性价比（⑤）
4. 成长能力（②）
5. 成长质量与盈利质量（②）
6. 资本回报与资本使用效率（②）
7. 安全边际（⑥）
8. 多期限预期收益与下行风险（⑦）
9. 数据质量及模型置信度（①）

**成长能力既参与独立评分，也必须参与合理估值与未来盈利预测**（同一份成长数据，
在"估值"里是输入假设，在"评分"里是维度分 —— 这是允许的，因为用途不同）。
**行业估值既影响估值评分，也参与多期限风险收益分析**。

### 8.2 去重表（防止同一信息重复加分）

| 信息 | 唯一归属 | 其它位置的处理 |
|---|---|---|
| 行业估值分位低 | 维度 2（行业估值） | 维度 3 只能用"个股 vs 行业的**差值**"，不得再用行业绝对水平 |
| 个股低于自身历史分位 | 维度 1 | 维度 7（安全边际）只用**绝对价值法**结果，不重复计入分位 |
| 成长能力高 | 维度 4 | 作为**假设输入**进入 ⑥⑦，但不再在 ⑥⑦ 里额外加分 |
| 成长质量高 | 维度 5 | 可触发风险约束**解除**，不等于加分 |
| 一致预期上调 | 维度 4 的辅助 | 不单独加分 |
| 股息率高 | 维度 1 或 8（按期限） | 同一期限只计一次 |

实现方式：评分器只接受**去重后的因子向量**，每个因子带 `owner` 字段，
`owner` 重复的因子在构建阶段就 panic / 报错（有单测钉住）。

### 8.3 评分流程

```
基础指标 → 各维度原始分（0~100） → 按期限加权综合分
        → 数据质量乘子（0.6~1.0）
        → 风险约束（预警 / 限制评级 / 无法评估）
        → 最终分 + 评级 + 风险旗标 + 置信度
```

- 各档期限**权重不同**（配置驱动，见 §12）。
- 权重、评分区间、行业调整规则、风险阈值**全部可配置**，并通过历史验证校准。
- **不把初始权重视为最优参数**（原方案 §7.2 明确要求）。

### 8.4 风险约束（九类，对应原方案 §7.3）

| 风险 | 判定 | 处置 |
|---|---|---|
| 估值低但盈利持续恶化 | 分位 < 30 且 TTM 净利润连续 2 季同比为负 | 限制评级上限 |
| 个股便宜但行业仍贵 | 个股折价 > 20% 且行业分位 > 70 | 限制评级上限 |
| 高增长但现金流差 | 增速分位 > 70 且现金含量 < 0.5 | 成长质量降级 + 预警 |
| 估值溢价但无基本面支撑 | 溢价 > 30% 且成长/质量分位 < 50 | 估值风险提高 |
| 预期收益高但悲观损失过大 | 风险收益比 < 1 | 限制评级上限 |
| 估值依赖乐观假设 | 乐观依赖度 > 阈值 | 强制降级 |
| 周期性误判 | 行业判为周期且 PE 低 + ROE 高位 | 预警 + 估值方法切换 |
| 数据缺失/过期/口径不一致 | 覆盖率 < 阈值 | 置信度下调或"暂无法可靠评估" |
| 多方法结果冲突 | 两法区间不重叠 | 降低置信度 + 点名冲突 |

**三级处置**：一般预警（仅标注）/ 限制评级（封顶）/ 无法可靠评估（不出评级）。
"不能只降低评分而不说明问题，也不能通过风险约束静默修改原始估值结果"——
原始估值与约束后评级**分开存储、分开展示**。

## 九、阶段⑨：指数性价比评估

指数用**独立模型**，不是成分股评分相加。

| 维度 | 计算 |
|---|---|
| 指数整体估值 | Σ成分自由流通市值 ÷ Σ成分 TTM 净利润（**调和加权**，等价于加权 PE 的正确算法） |
| 历史估值分位 | 在重建的指数 PE 序列上取分位（受 §2.2 约束 2 限制） |
| 成分盈利能力与成长 | 成分股 ROE / 净利润增速的加权与中位，两者并列 |
| 估值分布 | 成分 PE 分位分布、行业内分布、亏损成分占比 |
| 行业结构与集中度 | 行业权重、前 10 大成分权重、高估值成分（PE 分位 > 70）占比 |
| 安全边际成分权重 | 具备安全边际的成分股权重合计（**指数层面的"便宜货含量"**） |
| 整体盈利增长/现金流/资本回报 | 加权 ROE、加权现金含量、加权 capex/revenue |
| 多期限收益/风险 | 指数自身的波动、回撤 + 成分盈利预测 → 三情景 |

**明确禁止**：只用加权 PE 判断指数贵贱（会被少数高权重高估值股或高低估值股互相抵消误导）；
简单算术平均成分股评分。

输出：指数整体评分 + 五档期限评分 + 估值环境 + 成长结构 + 主要风险 + 置信度。
本机可用指数 8 个（`000001.SH 399001.SZ 399006.SZ 000688.SH 000300.SH 000016.SH 000905.SH 000852.SH`），
成分与权重只对 5 个指数存在（`000001.SH 399001.SZ 000300.SH 399006.SZ 000688.SH`）——
其余 3 个指数**只给指数自身估值与走势类结论**，成分结构类维度标"成分数据未入库"。

## 十一、阶段⑪⑫：历史验证

### 11.1 可验证与不可验证（诚实边界）

| 验证项 | 本机可做吗 | 原因 |
|---|---|---|
| 高评分 vs 低评分未来收益（12/36 个月） | **可做**（2022~2026 有全市场日线 + 财报） | — |
| 1/3/6 个月评分区分能力 | 可做，但样本重叠、噪声大 | 需用滚动评估日 + 独立样本区间 |
| 成长评分能否识别持续成长 | 可做（财报 2001 起） | — |
| 加入行业估值是否优于仅自身估值 | **部分可做** | 行业归属只有 2026-10 的 5 个快照 → 历史只能用当前归属近似，**必须标注前视偏差** |
| 成长调整估值是否优于单纯低估值 | 可做 | — |
| 计入分红/交易成本/公司行为 | 可做（`corporate_actions` 2023 起） | 2023 前无分红明细 |
| 指数评估验证 | 部分可做（指数 2021 起、8 个） | 成分历史缺失，指数估值序列只能自建 |

### 11.2 历史验证方法

- **滚动评估**：每月（或每季）一个评估日，只用该日之前已披露数据（`announce_date` 门控）；
- **分组检验**：按评分分 5 组，比较未来 1/3/6/12/36 个月的
  超额收益（相对沪深300 000300.SH）、风险调整收益、最大回撤、尾部风险（5% 分位）；
- **单调性检验**：组序与收益的秩相关（Spearman）；
- **对照实验**：仅自身估值 / 自身+行业 / 自身+行业+成长调整 —— 三组对比，回答验收标准 10；
- **稳定性**：分行业、分市场环境（牛/熊/震荡，用市场温度或指数均线状态划分）分别看。

### 11.3 防偏差（原方案明确要求）

- 无未来数据泄漏：所有输入带 `announce_date` / `as_of_date` 门控；
- 无幸存者偏差：股票池用**当时 `daily_bars` 里实际存在的代码**（含之后退市的，
  `trading_status` 有 `delisted` 标记），不用今天的清单；
- 无事后反复调参：参数集**版本化落盘**，验证结果与参数、评估日、数据指纹一起存档（
  `SourceSignature` 思路可复用）。

## 十四、验收标准（对应原方案 §13，逐条可测）

1. 同一评估日下同时输出：自身估值、行业整体估值、同行相对估值、成长调整后合理价值。✅ 可测
2. 能识别四种情形：个股低估但行业不便宜 / 个股相对便宜但基本面恶化 / 成长好但估值过高 / 两者都低但不便宜。✅ 有单测固定样例
3. 按行业与公司发展阶段选估值方法，不对所有股票统一标准。✅ 方法选择表 + 切换原因落库
4. 输出三情景价值区间、安全边际、估值置信度。✅
5. 1/3/6/12/36 个月独立评分与风险收益（参数表驱动，有单测断言五档参数不同、评分不全等）。✅
6. 成长能力·成长质量·行业估值·个股估值联合判断且不重复计分。✅ 去重表 + owner 校验单测
7. 输出全市场 / 行业 / 指数排名，并解释依据与主要风险。✅
8. 数据不足 / 方法不适用 / 模型冲突严重时明确提示，不强行结论。✅ "暂无法可靠评估" 状态
9. 历史评估使用当时可得数据，可追溯评估日 / 数据截止 / 模型版本。⚠ **部分**：财务与行情可时点正确；行业归属受 5 快照限制，历史场景标注前视偏差
10. 历史验证能检验加入行业估值与成长调整后是否改善区分能力与风险控制。⚠ **部分**：见 §11.1

> ⚠ 两项对原方案**如实降级**，原因是数据源事实（`industry_members` / `valuation_metrics` /
> `index_constituents` / `analyst_consensus` 在本机只有最近 5 个交易日）。
> 方案已把"时点正确"做进接口（一律 `asOf` 参数化），**数据一补齐即自动升级为完整满足**，
> 不需要改模型代码。

## 十五、最终设计原则（原方案 §14，固化为代码约束）

1. 不以近期涨跌幅作为性价比核心依据 → 评分器不接收任何"近期涨跌幅"因子。
2. 不只看个股自身估值 → 维度 1/2/3 三者缺一即降置信度。
3. 不将行业平均估值直接套用为所有个股合理估值 → 合理价值必须经成长调整（④）。
4. 成长能力既影响估值也影响独立评分与收益测算。
5. 成长速度与成长质量分开评价 → 两个独立字段、两个独立维度。
6. 相对估值与绝对估值交叉验证，冲突不取平均。
7. 个股与指数使用不同评估模型 → 两个独立入口，不互相调用评分。
8. 不同投资期限独立计算 → 参数表 + 单测禁止五档全等。
9. 评分/估值/风险结论均可解释、可追溯 → 每个分数带 `Evidence[]`。
10. 权重与阈值以历史验证为依据 → 全部可配置，初始值只是起点。
11. **不寻 PE 最低或跌幅最大的股票**，而是找风险收益匹配更好的标的。

## 十六、与需求方原始方案的差异说明

| 原方案 | 本方案落地 | 原因 |
|---|---|---|
| "个股与行业历史估值数据"（假设已有） | **自建重建**历史 PE/PB/PS 序列 | 本机 `valuation_metrics` 只有 5 天 |
| "行业分类及历史行业归属" | 当前归属可用；历史归属受限并标注 | 本机 `industry_members` 只有 5 个快照 |
